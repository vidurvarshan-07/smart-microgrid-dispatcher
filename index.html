ABSTRACTION

EnergySource (ABC)

Defines abstract template for any grid energy supplier with abstract method get_available_power(). Hides internal complexities of sun irradiation or wind dynamics from the dispatcher.

class EnergySource(ABC):
    @abstractmethod
    def get_available_power(self) -> float:
        raise NotImplementedError
INHERITANCE

Concrete Sources

SolarPlant, WindTurbine, BatteryStorage, and MainGridBackup all inherit common attributes (name, capacity_kw) and base behavior from EnergySource.

class SolarPlant(EnergySource):
class WindTurbine(EnergySource):

POLYMORPHISM

Uniform Dispatch Iteration

The dispatcher invokes source.get_available_power() on every source in its list without needing to know whether it's solar, wind, battery, or utility backup.

for source in self.sources:
    # Polymorphic method call
    available = source.get_available_power()
    taken = min(available, needed)
ENCAPSULATION

BatteryStorage Protection

_current_storage_kwh is strictly private and cannot be corrupted directly. It is guarded and clamped by charge(), discharge(), and set_storage_kwh().

self._current_storage_kwh = max(0.0, 
    min(initial_kwh, capacity_kwh))
def discharge(self, kwh: float):
    actual = min(kwh, self._current_storage_kwh)
    self._current_storage_kwh -= actual
COMPOSITION & ASSOCIATION

PowerDispatcher Controller

Composition: Dispatcher owns its energy sources (they are an integral part of the microgrid).
Association: Dispatcher interacts with independent ConsumerGrid objects, allocating power by priority tier.
